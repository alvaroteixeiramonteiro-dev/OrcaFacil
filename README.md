# OrçaFácil

A simple Android application for estimating service costs, built with Kotlin and XML layouts.

## Planned features

- Enter a service description, estimated hours, hourly rate and additional expenses.
- Calculate and display an itemized estimate.
- Edit the entered values or start a new estimate.
- Navigate through three Activities, with a splash screen at startup.

## Technologies

- Kotlin
- Android SDK
- XML layouts
- Android Studio
